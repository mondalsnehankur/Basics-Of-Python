# Python Practice Questions (Q1–Q80)

A collection of 80 beginner-to-intermediate Python programs covering core language fundamentals — variables, arithmetic, strings, conditionals, lists, tuples, sets, and dictionaries — framed as small real-world systems (billing, inventory, records, etc.).

All programs are combined into a single Jupyter notebook: **`combined_questions_1_80.ipynb`** (80 cells, one per question, in order).

## Topics Covered

| Range | Focus Area |
|---|---|
| Q1–Q10  | Arithmetic operations, variables, string basics |
| Q11–Q20 | String methods, string indexing, lists |
| Q21–Q27 | Lists, tuples |
| Q28–Q32 | Sets and set operations (union, intersection, difference) |
| Q33–Q40 | Dictionaries, conditionals |
| Q41–Q50 | Nested/chained conditionals, weighted calculations |
| Q51–Q60 | Dictionaries + conditionals combined, formatted reports |
| Q61–Q70 | Multi-step billing logic, dict/set operations |
| Q71–Q80 | Conditional categorization, combined multi-concept systems |

## How to Run

**Option 1 — Notebook (recommended)**
```bash
jupyter notebook combined_questions_1_80.ipynb
```
Run cells individually (each cell is self-contained and independently runnable) or run all via "Run All".

**Option 2 — Individual scripts**
Each question is also available as a standalone `.py` file (`q01_...py` through `q80_...py`) and can be run directly:
```bash
python q01_student_fee_management.py
```

## Requirements

- Python 3.7+
- No external libraries required (standard library only)
- Jupyter Notebook / JupyterLab (only needed for the `.ipynb` file)

## Structure Notes

- Each cell/script is independent — no shared state or imports between questions.
- Output is printed directly to console/cell output using formatted `print()` statements.
- Later questions (Q41 onward) build on earlier concepts, combining conditionals, collections, and formatted string output into more complete "systems".
